# Viral Replicator — Core War Memory Arena

Браузерный симулятор эволюции самовоспроизводящегося вирусного байткода в кольцевой памяти 16К (128×128). Код-организмы копируют себя, мутируют и конкурируют за выживание; процесс виден вживую на canvas, а статистика показывает циклы, популяцию, штаммы и поколения.

## Запуск

Открыть `index.html` в браузере. Сборка и зависимости не нужны.

## Возможности

- Запуск, пауза и пошаговое выполнение; сброс арены.
- Слайдеры скорости, мутаций, стартовой популяции и радиации.
- Инспектор памяти: адрес, значение, штамм и мнемоника.
- График разнообразия штаммов, звук, снимки и запись симуляции.

## Структура

- `index.html` — разметка и логика симуляции.
- `src/style.css` — оформление интерфейса.
